# Démo Cursor iOS

Un projet de démonstration iOS créé avec Cursor.

## Description

Ce projet est une application iOS de démonstration qui sert de point de départ pour le développement d'applications iOS.

## Prérequis

- Xcode 14.0 ou supérieur
- iOS 15.0 ou supérieur
- Swift 5.7 ou supérieur

## Structure du projet

```
démo-cursor-iOS/
├── AppDelegate.swift
├── SceneDelegate.swift
├── ViewController.swift
├── Info.plist
└── Assets.xcassets/
```

## Installation

1. Clonez le dépôt
2. Ouvrez le projet dans Xcode
3. Compilez et lancez l'application

## Fonctionnalités

- Interface utilisateur de base
- Support du cycle de vie des scènes iOS 13+
- Architecture MVC
